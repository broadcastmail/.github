# Security

## Reporting a vulnerability

Email security@broadcastmail.com with a description of the issue, steps to reproduce, and the impact you think it has. I'll acknowledge within 7 days.

Don't open a public GitHub issue for security problems.

## Scope

**In scope**
- broadcastmail.com — the dashboard and API
- The Resend webhook receiver
- Authentication, session handling, and plan enforcement
- How your Supabase credentials and Resend API keys are stored and used

**Out of scope**
- Railway, Supabase, Resend, or Stripe infrastructure
- Denial-of-service attacks
- Social engineering

## Bug bounty

No bounty program. If you report something real, I'll credit you publicly if you want.

## Disclosure

I follow a 90-day disclosure timeline. If that doesn't work for your situation, email me.
